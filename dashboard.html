SQL Window Functions & Joins

استعلامات SQL المستخدمة لاستخراج البيانات ودوال النوافذ

كود SQL بصيغة PostgreSQL لحساب فترات الخمول وتصنيف المستخدمين (مكتوب على بيانات محاكاة)

1. دالة LAG() لحساب فارق الأيام بين الجلسات واكتشاف خطر الـ Churn: Dialect: PostgreSQL
WITH user_session_intervals AS ( SELECT user_id, session_id, event_timestamp, -- جلب توقيت الجلسة السابقة لنفس المستخدم LAG(event_timestamp, 1) OVER ( PARTITION BY user_id ORDER BY event_timestamp ASC ) AS prev_session_timestamp FROM product_analytics_events WHERE event_name = 'session_start' ) SELECT user_id, session_id, ROUND(EXTRACT(EPOCH FROM (event_timestamp - prev_session_timestamp)) / 86400, 1) AS days_between_sessions, CASE WHEN (event_timestamp - prev_session_timestamp) > INTERVAL '14 days' THEN 'High Churn Risk' WHEN (event_timestamp - prev_session_timestamp) <= INTERVAL '3 days' THEN 'Highly Engaged' ELSE 'Normal Active' END AS churn_risk_segment FROM user_session_intervals WHERE prev_session_timestamp IS NOT NULL ORDER BY days_between_sessions DESC;
2. دمج متعدد الجداول (INNER / LEFT JOIN) لحساب التحويل والإيراد لكل حملة: Dialect: PostgreSQL
SELECT c.channel_name, COUNT(DISTINCT u.user_id) AS total_signups, COUNT(DISTINCT s.subscription_id) AS paid_conversions, ROUND(COUNT(DISTINCT s.subscription_id) * 100.0 / NULLIF(COUNT(DISTINCT u.user_id), 0), 2) AS conversion_rate_pct, ROUND(SUM(s.monthly_price_usd), 2) AS total_generated_mrr FROM marketing_attribution_campaigns c INNER JOIN app_users u ON c.campaign_id = u.acquisition_campaign_id LEFT JOIN user_subscriptions s ON u.user_id = s.user_id AND s.status = 'active' GROUP BY c.channel_name ORDER BY total_generated_mrr DESC;
