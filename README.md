## 📊 Overview

This repository hosts an interactive Product Analytics Case Study and Portfolio built for data-driven product decision-making.

### Key Highlights:
1. **Conversion Funnel Analysis:** 5-stage user conversion telemetry from visitor to paid subscriber, isolating a 33.1% friction drop-off in user onboarding.
2. **Cohort Retention Heatmap:** Longitudinal weekly cohort retention matrix demonstrating the "Smile Curve" plateau at 32.8% (Week 4).
3. **Advanced SQL Window Functions:** Production PostgreSQL queries using `LAG()`, `LEAD()`, and `ROW_NUMBER()` to calculate user session intervals and flag churn risk.
4. **Data Cleaning & Quality Audit:** Vectorized data pipeline applying 18 automated cleaning rules (deduplication, median imputation, ISO 8601 timestamps) achieving a 96% Data Quality score.
5. **Event Taxonomy (GA4 & Mixpanel):** Structured event dictionaries and parameter tracking schemas.
